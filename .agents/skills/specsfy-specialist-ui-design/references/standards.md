# Padrões de UI para sistemas e dashboards

## Shells e layouts

- Console: sidebar persistente, header contextual e área de trabalho.
- Master-detail: lista preservada com detalhe adjacente ou rota ligada.
- Dashboard: filtros globais, KPIs comparáveis, tendências e exceções.
- Workflow: stepper somente quando a sequência é obrigatória e finita.
- Settings: categorias estáveis, busca quando extensa e salvamento previsível.

## Componentes de dados

- KPI: nome, valor, unidade, período, comparação e estado.
- Chart: pergunta clara, escala honesta, legenda e alternativa textual.
- Table: colunas priorizadas, ações previsíveis, paginação e seleção explícita.
- Filter: estado visível, contagem, limpar e URL quando compartilhável.
